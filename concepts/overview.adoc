= 深入瞭解NetApp Keystone

:allow-uri-read: 
:nofooter: 
:icons: font

[role="lead"]
NetApp Keystone 是一個提供 Keystone 儲存設備以服務形式 (STaaS) 的平台，這是一項隨用隨付的訂閱產品，適合偏好以營運費用方式使用，而非預付資本支出或租賃的企業。



[[keystone-staas-offering-and-services]]
== Keystone STaaS 產品與服務

Keystone STaaS 提供類似公有雲的儲存基礎架構採購、部署和管理模式。訂閱 Keystone STaaS 時，您可以選擇滿足您需求的資料儲存設備類型和效能服務層級。

Keystone STaaS 是定義儲存功能如何交付與使用的產品。服務是該產品可用的功能，標準服務包含在基礎訂閱中，而附加服務則可在您需要額外功能時購買。例如，進階資料保護（ADP）是一項附加服務，可為支援的組態提供同步的站台間鏡射。

這種區分有助於您了解訂閱包含哪些功能，以及哪些功能需要額外購買。如需標準與附加服務的相關資訊，請參閱 link:../concepts/supported-storage-services.html["Keystone STaaS服務"]。



[[storage-flexibility-and-operational-models]]
== 儲存設備靈活度和營運模式

Keystone STaaS 支援多種資料儲存設備類型和效能服務層級。您可以從內部部署儲存設備開始，並隨著需求變更來新增雲端服務。容量調整和雲端重新分配受您的訂閱條款規範。

Keystone STaaS 可以採用合作夥伴營運模式或客戶營運模式。詳情請參閱 link:../concepts/operational-models.html["Keystone中的運作模式"]。



[[key-benefits-of-keystone-staas]]
== Keystone STaaS 的主要優勢

* *成本效率*：針對承諾容量獲得可預測的成本，超出該承諾的使用量則依使用量計費。
* *資本效率*：無需大量前期投資即可存取企業儲存設備。
* *可擴充性*：隨著業務成長，增加儲存容量。
* *靈活度*：根據實際情況調整儲存設備方案，並將工作負載遷移到雲端。
* *雲端整合*：在單一訂閱下使用內部部署與雲端服務。
* *安全性*：利用進階的安全性措施與恢復功能來保護您的資料。
