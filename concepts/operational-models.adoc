= Keystone 的營運模式
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
NetApp Keystone 可透過 Keystone 儲存設備以服務形式 (STaaS) 和 Keystone XaaS 訂閱產品取得。Keystone STaaS 支援合作夥伴營運和客戶營運的營運模式，而 Keystone XaaS 則完全由 NetApp 合作夥伴交付。您的產品和營運模式決定了誰來管理您的儲存環境、處理日常營運，並提供支援。



[[keystone-staas-operational-models]]
== Keystone STaaS 營運模式

Keystone STaaS 營運模式定義了 NetApp、合作夥伴與客戶在整個服務生命週期中的職責。以下章節將說明合作夥伴營運與客戶營運模式。



[[partner-operated-model]]
=== 合作夥伴營運模式

合作夥伴可以做為服務供應商或經銷商來交付 Keystone STaaS。職責取決於您與合作夥伴的協議。請聯絡您的服務供應商或合作夥伴，以了解他們為您處理哪些任務。

*服務供應商*：服務供應商為其最終客戶營運服務。作為與 NetApp 簽約的一方，服務供應商管理多租戶環境。每個租戶都是服務供應商的客戶，並擁有分隔的訂閱，由服務供應商直接向其收費。服務供應商系統管理員負責為租戶執行所有管理任務。*經銷商*：作為經銷商，合作夥伴扮演 NetApp 與客戶之間的橋樑。合作夥伴向最終客戶銷售 Keystone 服務並管理發票。雖然由合作夥伴負責計費，但由 NetApp 直接為客戶提供支援。Keystone 支援與客戶互動，並處理租戶的所有管理任務。



[[customer-operated-model]]
=== 客戶營運模式

在客戶自主營運模式下，您可以根據儲存設備需求和所選效能服務層級訂閱 Keystone STaaS。NetApp 會定義架構和產品，並在您的場所部署儲存設備。

您的儲存設備和 IT 團隊管理基礎架構。您組織中的系統管理員負責為環境中的使用者執行管理任務。根據您的合約，您可以向 NetApp 或您的服務供應商提交服務請求。

[[keystone-xaas-partner-delivery-and-support]]
== Keystone XaaS 合作夥伴交付與支援

Keystone XaaS 是 NetApp Keystone 旗下的分隔訂閱產品，完全由 NetApp 合作夥伴交付。合作夥伴向其最終客戶交付服務，並管理支援和日常營運。

如果您使用 Keystone XaaS，請聯絡您的直接合作夥伴以取得服務和支援。上文所述的 Keystone STaaS 營運模式與客戶營運責任表並未描述 Keystone XaaS 的責任。
