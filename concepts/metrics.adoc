= Keystone STaaS 儲存設備計量與定義
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Keystone STaaS 使用特定術語來衡量和報告您的儲存設備訂閱。了解這些術語有助於您解讀儀表板資料和訂閱報告。

[cols="1,3"]
|===
| 期限 | 定義 


| 容量（GiB、TiB、PiB） | 資料儲存容量以 1024 的冪來衡量：1 GiB = 1024^3^ 位元組，1 TiB = 1024^4^ 位元組，1 PiB = 1024^5^ 位元組。 


| IOPS | IOPS（每秒 I/O 運算元）是指應用程式每秒請求的協定運算元。IOPS 顯示在 Keystone 儀表板的操作計數器圖表中。 


| 可用度 | 可用度是指服務在一個月內成功回應的 I/O 請求數佔總 I/O 請求數的百分比。此計量在每月的服務分界點進行測量，不包括計畫內的服務停機或客戶提供的設施、網路或其他服務的不可用時間。 


| 耐久性 | 持久性是指在不遺失資料完整性的情況下可以存取的資料百分比，不包括客戶造成的刪除或毀損。 


| 延遲 | 延遲是指處理從用戶端接收的 I/O 請求所需的時間，在服務分界點（儲存控制器 I/O 連接埠）處測量。 
|===
